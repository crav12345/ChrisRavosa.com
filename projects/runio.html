RUNIO

Full-Stack Engineering

Backend Engineering

Runio is a full-stack web application I designed and built end-to-end, centered on delivering an excellent reading experience for public domain classic novels. The catalog spans titles from Homer to Mary Shelley, each surfaced with AI-generated cover art and tagged by genre.

I designed the frontend around reading ergonomics — carefully tuning typography, line length, contrast, and scroll behavior to reduce eye strain across long sessions. The interface supports light and dark modes and includes search and sort across the full library.

On the backend, I built and deployed the server infrastructure responsible for sourcing, storing, and serving novel content. User accounts allow readers to track progress and pick up where they left off.
